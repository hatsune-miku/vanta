# VANTA

横版高速动作网页游戏（纯战斗）。Phaser 4 + Three.js + Vite + TypeScript。

Phaser 负责战斗、场景、HUD 和特效；Three.js 将角色骨骼模型绘制到透明画布，再作为 Phaser 的角色图层合成。主角采用 Kai Sama 的 Elle 模型，调整为银白发、青蓝材质，并适配 Quaternius 动作库；敌人采用 Quaternius 基础模型，服装、护甲、武器、场景和特效为程序生成。当前版本关闭全部音效与背景音乐，不创建音频上下文。

线上地址：https://vanta.vanillacake.cn

## 操作

| 按键 | 动作 |
|---|---|
| A / D | 移动 |
| 空格 | 跳跃（可二段跳，↓ + 空格 下平台） |
| J | 轻攻击（连按五段，空中三段） |
| I | 重攻击（连按三段：横扫 → 升斩 → 跃斩；↑ + I 挑空；轻击后接 I 为派生技；空中 I 为下砸） |
| O / Shift | 闪避（八方向瞬移，连续光带与残影显示实际行动轨迹）。在敌人攻击即将命中的瞬间闪避，或闪避路径触碰敌方攻击，均触发极限闪避：免除受击、获得 30 能量并对攻击者造成 72 点基础伤害（没有提示，靠读敌人动作）。三分之二屏内有锚点时，闪避会直接到最近的锚点 |
| L | 处决（目标空血进入濒死后，头顶显示 L 按键；屏幕内任意距离可发动） |
| U | 过载（持续 15 秒，结束后冷却 5 秒） |
| 过载时长按 J + I | 蓄力剑气（最多 1.5 秒；松开任一键或蓄满后释放，随后退出过载） |
| Esc / P | 暂停 |

支持标准映射手柄，标题页可直接按手柄按键进入。按 Xbox 键位标记：左摇杆/方向键移动，A 跳跃，X 轻击，Y 重击，B/RT 闪避，RB 处决，LB / 左摇杆按下开启过载，Start 暂停。

过载期间，尚未使用过的敌人提供闪避锚点，沿用锚点距离与方向选择，并优先选择敌人。每个敌人仅能作为一次锚点：闪避出发时消耗其锚点属性，后续开启过载或 Boss 换命也不会恢复。同一时刻触发极限闪避时，优先播放反击演出。抵达敌人锚点时触发一次基础伤害为 75 的斩击，计入过载加成后为 90，可使满血初级兵进入濒死。重击连段、挑空、回旋和下劈的范围及对应光效扩大到 1.25 倍，每段重击造成两次伤害，并使用粉蓝双色。普通与过载模式的重击均可抵消命中范围内的敌方子弹。所有对敌伤害直接乘以 1.2，包括蓄力剑气和反击。开启过载时，以一次强烈闪光、光柱和爆裂碎光突出入场，同时从玩家中心发出与处决波纹同范围、同速度的不可见清弹波纹。HUD 以两侧粉蓝边光、发亮状态框显示过载，剩余时间居中靠上显示，冷却与蓄力进度保留在左上状态区；暂停冻结计时，命中停顿及慢动作不会延长时长，重开重置状态。

过载中同时按住轻击与重击（键盘 J + I／手柄 X + Y）开始蓄力，系数在 1.5 秒内从 6 线性提升至 12。松开任一键、达到 1.5 秒或过载到期时，释放贯穿战场的剑气并退出过载；剑气以第一段重击的单次 20 点伤害为基准，最终伤害为 `3 × 蓄力系数 × 20 × 1.2`，即 432～864。剑气保持垂直，从屏幕左侧进入，以每秒 400 个画面坐标单位向右平移，吞掉路径上的敌方子弹、穿过所有沿途目标并从右侧离开；不随角色朝向反转，不绕中心公转，并保留发射时的过载加成。真正受伤时中断蓄力，能量护盾抵挡的攻击不会打断。

玩家受击时，每完整 20 点能量可抵挡一次攻击，扣除 20 点后免除扣血、受击动作和击退。少于 20 点不触发护盾；HUD 按完整格数向下取整显示。持续命中框只扣一次能量。闪避优先于护盾，子弹、地火和落雷均可触发极限闪避；反击使用所有敌人通用的独立穿身斩，正常速度接近并斩中，在接触时结算一次 72 点基础伤害；命中特效展开到峰值后以 0.16 倍速穿到目标另一侧，不强制击倒或扣除 Boss 命数，也不提供处决回血与奖励。

敌人仅使用生命值：空血进入持续的濒死状态，可发动处决；濒死时再次受到正伤害则直接击倒。若单次最终伤害达到生命上限的 2.0 倍，则跳过濒死直接击倒。关底 Boss 有 3 条命，每条 500 血，血条右侧显示剩余命数。多于一条命时，过量伤害仍先进入濒死；处决强制击倒并消耗一条命，倒地恢复期间无敌，随后补满下一条命。最后一条命遵循普通敌人的过量伤害规则。没有耐力条、破防积累或低血自动破防。可交互目标旁显示 O / L 按键帽，选中目标的图标更亮，不再使用全局锚点／处决文字提示。

暂停会冻结战斗、镜头与场景动画；暂停期间的攻击输入不会带入恢复后的战斗。死亡后从当前封锁区重试，通关后从第一个区域重新开始。

## 开发

```
pnpm install --frozen-lockfile
pnpm dev            # 本地开发 http://127.0.0.1:5173
pnpm build          # 类型检查 + 构建到 dist/
pnpm run deploy     # 本机构建，通过 SSH 发布到 vanillacake.cn
```

调试参数：`?arena=2` 从指定封锁区开始（0–3，3 为 Boss），经过标题页后生效。

动画预览：开发服务器下访问 `/tools/preview3d/index.html`，或运行 `pnpm art:preview` 生成完整姿势图。旧的 `?gallery&set=...` 入口已不适用于当前版本。

## 发布

- 访问地址：<https://vanta.vanillacake.cn>，由 Nginx 直接提供服务。
- 源站 SSH：`miku@vanillacake.cn`，本机已配置免密登录。
- 静态目录：`/var/www/vanta/`，属主为 `miku`，常规发布无需 sudo。
- Nginx 配置：`/etc/nginx/sites-available/vanta`，已链接到 `sites-enabled/vanta`。
- HTTPS 证书：`/etc/letsencrypt/live/vanta.vanillacake.cn/`，`snap.certbot.renew.timer` 已启用。
- Nginx 配置副本：`tools/deploy/vanta.nginx`。HTTP 自动跳转 HTTPS；ACME 验证目录为 `/var/www/letsencrypt/`。
- 证书续期后由现有的 `reload-nginx.sh` deploy hook 自动重载 Nginx，续期演练已通过。

在本机项目目录执行：

```sh
pnpm test
pnpm test:live
pnpm run deploy:check  # 构建并预演同步，列出将更新、删除的文件，不改动线上
pnpm run deploy       # 构建并同步 dist/ 到源站
VANTA_URL=https://vanta.vanillacake.cn node tools/live.mjs  # 公网操作回归
```

构建在本机完成，源站使用 SSH 和 rsync 接收静态文件。同步会移除站点目录中不再属于构建产物的文件，并排除 `.DS_Store`；更新静态文件无需重载 Nginx。

站点首页和模型使用 `Cache-Control: no-cache`，带哈希的 `/assets/` 使用一年不可变缓存。发布后检查首页及其引用的脚本、`/models/Elle_Vanta.glb`、`/models/UAL1_Standard.glb`、`/models/UAL2_Standard.glb` 和 `/credits.html` 均返回 200，再验证标题页进入战斗。

## 模型与动画

- `assets-src/models/` 保存原始模型及各自授权说明。Elle 采用 CC BY 4.0，Quaternius 模型和动作库采用 CC0，不能将全部资源标为 CC0。
- `src/art/anims.ts` 将固定逻辑帧映射为动画时间，攻击动作的关键帧对齐命中时刻。
- `pnpm models:pack` 根据动画表裁剪资源，再将动作烘焙到 Elle 的 VRoid 骨骼并写入 `public/models/`。增加动画引用后需要重新打包；缺失动画会令命令失败。
- `tools/pack-elle.mjs` 处理 Elle 的坐标和尺寸、精简骨骼矩阵、压缩贴图，并按 60Hz 烘焙动画，保留原动作时长。无需 Blender 或运行时重定向。
- `tools/hero-motion.mjs` 在烘焙时塑造主角的站姿、拖剑跑姿、收膝跳跃、挥刀时的躯干扭转与抬手引爆动作；敌人继续使用原动作。轻击用分段时间映射表现蓄势、瞬间挥出和收势。
- `src/three/elle.ts` 合并 Elle 的网格并设置银白发、青蓝材质；保留原贴图细节与完整服装。
- `src/three/stage3d.ts` 管理角色、武器、骨骼挂点与残影。角色挂点在逻辑步和渲染时均更新；重开会释放实例资源，保留共享模型。
- `src/three/costume.ts` 在绑定姿势下生成服装和护甲，按材质合并成骨骼网格。每种外观共享几何体，每个角色独立控制闪光、发光与透明度；残影使用相同的服装轮廓。

主角来源：[Elle — Sci-Fi Anime Girl](https://sketchfab.com/3d-models/elle-sci-fi-anime-girl-e16bf07a62e54b8ea99ca2653675bb41)，作者 [Kai Sama](https://sketchfab.com/kaisamafab)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。完整署名与改动说明在 `public/credits.html` 和模型旁的 `LICENSE-Elle-CC-BY.txt` 中，标题页提供入口。

## 光效参考

`assets-src/vfx/REFERENCES.json` 记录素材来源和使用方式。已收集 Cethiel 的 Weapon Slash - Effect 及 Kenney 的 Particle Pack 原始压缩包、预览与许可信息，供后续美术迭代使用。运行时的高饱和体积刀光和垂直剑气由 `src/art/bladeFx.ts` 生成，采用不规则曲率、宽窄变化和撕裂内缘，叠加半透明体积、饱和辉光与断续高亮刃线；普通模式保持单刃，过载模式保留错位的蓝粉双刃。参考包不加入线上下载资源。

## 自动化测试

逻辑以固定 60Hz 步进，`?test` 模式下由脚本手动推进，不依赖实时帧率，适合无 GPU 的机器。

```
pnpm exec playwright install chromium           # 首次测试前安装浏览器
pnpm test                                        # 输入/重开流程 + 3D 接入 + 全流程对战 + 处决分镜
pnpm test:flow                                   # 连按、多键绑定、失焦、暂停与死亡/通关重开
pnpm test:combat                                 # 命中停顿、跳跃高度、核心爆炸与震屏、单环清弹
pnpm test:enemy                                  # 濒死、过量伤害、Boss 终结规则、目标按键提示
pnpm test:overload                               # 过载时长、冷却、伤害、锚点斩击、重击范围及双色光效
pnpm test:advanced                               # 双段重击、路径闪避、清弹、蓄力贯穿、Boss 多命与空中处决同步
pnpm test:revision                               # 能量格护盾、地火反击、多命保护、一次性锚点、垂直剑气与静音
pnpm test:rig                                    # 服装骨骼、材质、残影、挂点、枪口与资源回收
pnpm test:bot                                    # 自动对战，必须通关才通过
pnpm test:exec                                   # 验证处决与冲击波，分镜截图到 tools/out/
pnpm test:live                                   # 生产构建的键盘操作与标准 Gamepad 接口模拟回归
pnpm art:preview                                 # 六种实战外观与双向动作，截图到 tools/out/preview3d.png
```

自动对战会补充玩家生命值，用于流程与运行时回归，不代表难度和平衡性验收。实时测试等待实际游戏状态变化，软件渲染环境也可运行。

命中反馈：轻击停顿 5–7 帧，重击和终结段 10–15 帧，配合更亮的高饱和体积刀光和命中火花；普攻与重击中，每道刀光的明暗层使用相同位置、角度和尺寸，普通模式合为单刃、过载模式保留错位双刃，以多层饱和辉光和高亮刃线突出刀光；挥空不触发停顿。非处决攻击不触发震屏或镜头缩放冲击。处决首个爆发或斩击就发出单道水波纹，按线性速度在 0.72 秒特效时间内扩散，连锁处决会替换余波。普通兵、枪手与无人机先被快速挑空，主角立即跳起斩击一次，斩击同时穿过目标身体并引爆核心，散出方向、速度与长短不一的细针碎光，大型敌人保留斩击；处决震屏峰值为 20–26，绽放处决的起跳、斩击和绽放展开以正常速度播放，绽放刚达到最大尺寸和亮度时才进入 0.16 倍速的穿身余段，持续约 0.63 秒，并对位移和角色动作逐帧插值；随后以正常速度短暂收势并交回控制。处决与完美闪避反击共用特效峰值触发规则，后续演出也以视觉峰值作为慢放起点，角色留在目标另一侧半空，可立即接空中攻击；大型敌人在爆发后 16 个演出帧恢复控制。碎光和目标消散在恢复操作后继续，丢弃演出期间缓存的攻击输入并清除余震。

跳跃高度按固定 60 Hz 的实际顶点调整为原来的 1.5 倍：普通跳 468、二段跳约 368，最短轻点跳约 82.5 个世界单位。

## 结构

- `src/art/` 程序化贴图、动画时间映射、披风与场景背景
- `src/three/` Three.js 模型、武器、骨骼挂点、残影与无人机精灵适配
- `src/game/` 角色、敌人与 Boss、特效（含水波纹）、处决演出
- `src/scenes/` 启动、标题、战斗主场景、HUD
- `src/core/` 键盘/手柄输入、输入缓冲与确定性随机数
- `tools/` 自动对战、运行时回归、截图与模型处理
- `.claude/skills/` Phaser 官方 Agent Skills（随 phaser 包分发）
