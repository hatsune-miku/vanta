# VANTA

横版高速动作网页游戏（纯战斗）。Phaser 4 + Three.js + Vite + TypeScript。

Phaser 负责战斗、场景、HUD 和特效；Three.js 将角色骨骼模型绘制到透明画布，再作为 Phaser 的角色图层合成。主角采用 Kai Sama 的 Elle 模型，调整为银白发、青蓝材质，并适配 Quaternius 动作库；敌人采用 Quaternius 基础模型，服装、护甲、武器、场景和特效为程序生成。声音目前只有背景音乐和区域肃清的提示音，见下文「声音」。

线上地址：https://vanta.vanillacake.cn

## 操作

| 按键 | 动作 |
|---|---|
| A / D | 移动 |
| 空格 | 跳跃（可二段跳，↓ + 空格 下平台） |
| J | 轻击（连按五段，空中三段）。空中 ↓ + J 为下劈 |
| I | 重击（连按四段，地面与空中都能打完：上挑斩 → 转身反手斩 → 残影三连 → 齿轮下砸；↑ + I 挑空；轻击后接 I 为派生技；空中 ↓ + I 为重下劈）。长按 I 为闪避重击 |
| O / Shift | 闪避（八方向瞬移：人物以半透明的弓步前冲姿态穿过这段距离，身后拖出若干道长短、粗细、起止和斜度都各不相同的线条标示路径（每次闪避都不一样），约 0.2 秒就消失，不再留下一串残影）。在敌人攻击即将命中的瞬间闪避，或闪避路径触碰敌方攻击，均触发极限闪避：免除受击、获得 30 能量并对攻击者造成 72 点基础伤害，这一击若足以致命则直接击倒、不进入濒死（没有提示，靠读敌人动作）。超载中，三分之二屏内有尚未用过的敌人时，闪避会直接闪到它身边并斩击（地图上不再有固定锚点） |
| L | 处决（目标空血进入濒死后，头顶显示 L 按键；屏幕内任意距离可发动） |
| U | 超载（持续 15 秒，结束后冷却 5 秒） |
| 长按 J + I | 光幕（按住蓄力）。普通模式按格消耗能量（至少 2 格才能开始，冷却 5 秒），放出贯穿战场的剑气；超载中不耗能量，时间放慢并转为俯视视角，松开后斩下覆盖全屏的粉色剑气并退出超载 |
| Esc | 打开作战终端，游戏在它后面静止：选择关卡（确认即从该关开头开始）、进入技能页、开关声音、查看资源署名。再按 Esc 返回战斗 |
| K | 直接打开技能页（终端里也能进）：W / S 切换技能，逐个说明按法和效果 |
| M | 静音 / 恢复声音（会记住选择） |

支持标准映射手柄，标题页可直接按手柄按键进入（标题页任意键继续）。按 Xbox 键位标记：左摇杆/方向键移动，A 跳跃，X 轻击，Y 重击，B/RT 闪避，RB 处决，LB / 左摇杆按下开启超载，Start 打开作战终端，Back 打开技能页，终端里用 A 确认。

普通攻击与重击的基础伤害：轻击五段 10 / 10 / 12.5 / 7.5 + 10 / 22.5，空中三段 8.75 / 8.75 / 17.5，下劈 8.75、落地 10；重击四段 25 / 30 / 12 × 3 / 7 × 至少 5 + 32，挑空 15，回旋 7.5 + 7.5 + 18.75，重下劈 10、落地 20。重击四段的范围都比以前大得多（第一、二段向前约 500～570，超载再乘 1.25）：

1. 上挑斩：原地蓄势后向前上方斩出，不再转身。
2. 转身反手斩：转身、换到另一只手反握，向斜下方斩出；判定在正前方、不偏下，出手快、距离最长，是连段里最实用的一段。命中时停顿更长（16 帧），被击中的敌人身上绽开一朵略弱于处决的光花（只是特效；一刀最多两朵，只有第一朵带全屏泛光），小体型敌人原地僵直 0.8 秒而不是被打飞。
3. 残影三连：本体像信号丢失一样消失且无法被击中，三道残影在前方不同位置各斩一次。本体不移动；残影斩完后本体并不立刻现身，而是继续隐去，直到这一段完全结束（或被闪避、跳跃、轻击、走动打断）才在原地重新出现，接第四段时则直接出现在空中。
4. 齿轮下砸：在第三段出手位置的上空出现，高速旋转斜向砸下，主角以每帧约 0.38 圈（每秒约 23 圈）的速度旋转，快到看不清人形，画面上是一个持续转动的刀光之轮而不是一刀一刀的斩击；伤害仍按咬合结算，沿途每 4 帧一次，贴身的敌人至少吃到 5 次，落地时再有一次范围更大、特效最重的斩击（不定格）：被击中的敌人身上同样绽开光花（比第二段稍强），小体型敌人僵直约 1.1 秒。

重击每一段出手后都有一小段后摇，用来放慢连段的节奏：后摇期间闪避、跳跃、轻击、处决、蓄力和直接走开都立即生效，不会僵直；只有接下一段重击要等后摇结束（第一、二、三段各约 0.15～0.18 秒，落地那一段约 0.27 秒）。后摇里按下的重击会被记住，后摇一结束就接上；按住方向键走开后不久再按重击，连段也从下一段继续而不是从头开始。主角做完一个动作后，用大约三分之一秒缓缓收回站姿。

空中闪避不限次数：每次空中闪避结束后主角会在原地滞空约 0.43 秒（比闪避冷却长），所以可以一次接一次地在空中闪避飞行而不掉高度；滞空中按住 ↓ 或再跳一次会放弃滞空。

空中按 I 同样从第一段打起并悬停出招；只有 ↓ + I（重下劈，带落地冲击波）和 ↓ + J（下劈，更快更窄）会直接下落。一次滞空里只有前几招会上浮，悬停次数用完后正常下落。

闪避重击：长按 I（约 0.17 秒）时，第一段变成向前闪避，撞到敌人就停下并立刻斩出第一段；最远为普通闪避的 1.25 倍，途中无敌，到头没有敌人也照常斩出，之后连按 I 接后续段。轻点 I 仍是原地的第一段。

战斗中不显示伤害数字，命中反馈由停顿、火花和敌人血条承担；处决回血仍显示 +14。

超载期间，尚未使用过的敌人提供闪避锚点，沿用锚点距离与方向选择，并优先选择敌人。每个敌人仅能作为一次锚点：闪避出发时消耗其锚点属性，后续开启超载或 Boss 换命也不会恢复。同一时刻触发极限闪避时，优先播放反击演出。抵达敌人锚点时触发一次基础伤害为 75 的斩击，计入超载加成后为 90，足以直接击倒满血初级兵。重击连段、挑空、回旋和下劈的范围及对应光效扩大到 1.25 倍，每段重击造成两次伤害，并使用粉蓝双色。普通与超载模式的重击均可抵消命中范围内的敌方子弹。所有对敌伤害直接乘以 1.2，包括蓄力剑气和反击。开启超载时，以一次强烈闪光、光柱和爆裂碎光突出入场，同时从玩家中心发出与处决波纹同范围、同速度的清弹波纹，整个画面随之荡开一圈水波纹（这圈波纹曾被改成不可见，现已恢复）。超载时画面四周合拢一圈鲜明的粉紫色光框，整个画面带一层很淡的粉色，剩余时间居中靠上显示（左上状态区不再加框，冷却不再单独显示）；暂停冻结计时，命中停顿及慢动作不会延长时长，重开重置状态。

普通模式下同时按住轻击与重击（键盘 J + I／手柄 X + Y）也能蓄力：开始时支付 1 格能量，之后每满 1 秒再支付 1 格，2 秒内最多支付 3 格，蓄满 2 秒、松开任一键或能量提前用完时释放同样的贯穿剑气；能量不足 2 格不能开始，释放后冷却 5 秒。系数在 2 秒内从 6 线性提升至 12，最终伤害为 `3 × 蓄力系数 × 20`，即 360～720。

这道贯穿剑气使用独立的 20 点基准伤害，不随普通攻击与重击的基础伤害调整。它保持垂直，从屏幕左侧进入，以每秒 1000 个画面坐标单位向右平移（原为 400），吞掉路径上的敌方子弹、穿过所有沿途目标并从右侧离开；不随角色朝向反转，不绕中心公转。按着 J + I 不放时，一次蓄力释放后不会自动接下一次，必须松开再按。

超载中同时按住轻击与重击则是另一招，不消耗能量，最多蓄 1.5 秒：

- 蓄力期间，除主角以外的一切都放慢到原速的十分之一。
- 主角跃起约 300 像素，画面从侧视转为俯视的三维视角：平面场景暗下去，只留下立体的角色站在一片蓝色网格地面上，每个敌人脚下有一个粉色十字和一道短光柱，主角脚下是青色菱形标记。
- 松开任一键、蓄满 1.5 秒或超载到期时，主角转身向下连斩两刀（粉色，只夹少量蓝色细丝），随即退出超载、画面回到侧视。
- 第一刀只是先导：一道细而平的光刃以每秒 4200 的速度笔直落下，不造成伤害，也不在地面停留，直接穿过地面飞走；它身后留下一道贯穿整个画面高度的光路，停留约 0.7 秒后淡去。
- 0.3 秒后第二刀沿着这条光路落下，这一刀才有伤害：一道横贯全屏的巨大弧形光刃——刃身极厚，中间比两端低六百多像素，以每秒 6000 的速度坠落。刃身比先导厚得多，下落时身后拖着四层逐渐变淡、拉长的残像，沿途甩出竖直的光丝，显出速度。刃线触地的一刻画面剧烈震动（幅度是处决的两倍多）、荡开一圈水波纹，整条接触线同时迸出电焊般的火花；随后速度降到十分之一并压在地面上拖行 2 秒，拖行期间火花和蓝白色的弧光闪烁不断、画面持续震颤，上方的光幕被逐渐压低，之后恢复原速沉入地面消失。
- 第二刀存在期间，每 0.1 秒对画面内所有敌人造成一次第一段重击的伤害（25，带 1.2 倍超载加成即 30），并清除画面内的敌方子弹；整段大约 22 次。

真正受伤时中断蓄力，能量护盾抵挡的攻击不会打断。

玩家受击时，每完整 20 点能量可抵挡一次攻击，扣除 20 点后免除扣血、受击动作和击退。少于 20 点不触发护盾；HUD 按完整格数向下取整显示。持续命中框只扣一次能量。闪避优先于护盾，子弹、地火和落雷均可触发极限闪避；触发的那一刻先有约 0.43 秒的全局慢放（0.12 倍速），同时镜头给主角一个幅度很小的特写（只略微推近约 13%、稍稍偏向她），随后才进入反击；反击使用所有敌人通用的独立穿身斩，正常速度接近并斩中，在接触时结算一次 72 点基础伤害。这一击的特效与处决完全相同、不做削弱：按目标体型取处决的绽放尺寸（小体型 1.3、常规 1.55、大体型 1.9），同样的全屏泛光、水波纹、震屏和重度动态模糊；绽放展开到峰值后以 0.16 倍速穿到目标另一侧。它仍然只是一次普通伤害：不强制击倒或扣除 Boss 命数，也不提供处决回血与奖励。

敌人仅使用生命值：空血进入持续的濒死状态，可发动处决。濒死的敌人不容易被误杀：之后的普通伤害先累计，累计达到其生命上限（至少 80）才会不经处决直接倒下；通过闪避打出的斩击则立即将其击倒。濒死的敌人身上带有标识：机体泛起粉色的脉动辉光，核心位置亮起一个闪烁的高亮光点和一道横向镜头光芒，细小的电弧不时在身上游走。动作也随之改变：普通兵和枪手先踉跄后仰，再弯腰摇晃；重装兵、攻城机体和 Boss 单膝跪地、低头，武器头落在地面上撑在身前（不会穿到地面以下），头顶标记、血条和处决演出的落点随之降低；无人机倾斜并抖动。若单次最终伤害达到生命上限的 2.0 倍，则跳过濒死直接击倒。通过闪避打出的斩击（极限闪避反击、超载锚点斩击）只要把生命打空，同样跳过濒死直接击倒；Boss 还有多条命时被击倒并扣除一条命。关底 Boss 有 3 条命，每条 500 血，血条右侧显示剩余命数。多于一条命时，过量伤害仍先进入濒死；处决强制击倒并消耗一条命，倒地恢复期间无敌，随后补满下一条命。最后一条命遵循普通敌人的过量伤害规则。没有耐力条、破防积累或低血自动破防。可交互目标旁显示 O / L 按键帽，选中目标的图标更亮，不再使用全局锚点／处决文字提示。

游戏开场是一段约 4700 像素长的走廊，在第一封锁区之前。这里不是关卡式的教程：没有任务、没有门槛，也不需要跳过。按键说明做成了场景里的全息牌，从左到右依次立着，主角走近时一块一块展开（一道光线向两侧拉开，牌面从线里张开，键帽和名字逐个亮起）；牌上的名字就是这些技能的正式名称，接入手柄时键帽改显示手柄键名：

1. `J` 轻击、`I` 重击、`L` 处决——牌后站着 2 个小怪。
2. `O` 闪避——这里什么都不放；极限闪避不再专门教。
3. `J + I` 光幕——走到这里时能量补满，牌后站着 10 个小怪。
4. `U` 超载——牌后站着 5 个小怪。
5. `K` 技能详情——最后一块牌，指向终端里的技能页；这里什么都不放。

这些小怪（普通兵和枪手）只站着不出手，可以随便试招，也可以直接跑过去。走进第一封锁区时，剩下的小怪被撤走，击杀、处决、连击、用时和承伤统计清零，正式流程从这里开始。

走廊每次打开页面走一次：第一次进入从走廊最左端出发并放置小怪；阵亡或通关后重新开始时，主角直接出现在第一封锁区外，说明牌仍然立在走廊里，但不再放小怪。

HUD 很精简：左上角只有 VANTA 字样、生命条和能量格，超载时也不再给这一块加框；没有技能图标，也没有常驻的超载提示行——超载只在开启期间于屏幕上方居中显示剩余时间；指引只剩一个箭头。右侧连击数是斜体字，文字框右侧留了余量，数字不会再被截掉一块。

游戏没有单独的暂停页，也不响应 P 键。Esc 打开的「作战终端」是游戏里唯一的菜单，画成投在定格战场上的全息界面，展开方式和开场走廊的说明牌一样：

- 关卡页：列出全部关卡，右侧是所选关卡的实景和简介；W / S 选择，Enter / 空格（手柄 A）确认，从该关开头开始。攻击键不能确认，连打不会误选。下面几行是技能、声音开关、全屏（能全屏的环境才有）、资源署名（署名入口从暂停页挪到了这里），在 KOOK 里还多一行「退出游戏」。
- 技能页：左侧列出全部技能，右侧是所选技能的名称、按法和说明；W / S 切换。原本计划给每个技能配一段演示视频，在这台没有显卡的机器上逐帧录制太慢，已按要求跳过；以后要补的话，在有显卡的机器上录最省事。

暂停会冻结战斗、镜头与场景动画；暂停期间的攻击输入不会带入恢复后的战斗。死亡后从当前封锁区重试，通关后从第一个区域重新开始。

## 开发

```
pnpm install --frozen-lockfile
pnpm dev            # 本地开发 http://127.0.0.1:5173
pnpm build          # 类型检查 + 构建到 dist/
pnpm run deploy     # 本机构建，通过 SSH 发布到 vanillacake.cn
```

调试参数：`?arena=2` 从指定封锁区开始（0–3，3 为 Boss），经过标题页后生效。`?test&tutorial` 让脚本运行也从开场走廊出发（普通的 `?test` 直接从第一封锁区外开始，不建说明牌）。

动画预览：开发服务器下访问 `/tools/preview3d/index.html`，或运行 `pnpm art:preview` 生成完整姿势图。旧的 `?gallery&set=...` 入口已不适用于当前版本。

## 发布

- 访问地址：<https://vanta.vanillacake.cn>，由 Nginx 直接提供服务。
- 源站 SSH：`miku@vanillacake.cn`，本机已配置免密登录。
- 静态目录：`/var/www/vanta/`，属主为 `miku`，常规发布无需 sudo。
- Nginx 配置：`/etc/nginx/sites-available/vanta`，已链接到 `sites-enabled/vanta`。
- HTTPS 证书：`/etc/letsencrypt/live/vanta.vanillacake.cn/`，`snap.certbot.renew.timer` 已启用。
- Nginx 配置副本：`tools/deploy/vanta.nginx`。HTTP 自动跳转 HTTPS；ACME 验证目录为 `/var/www/letsencrypt/`。
- 证书续期后由现有的 `reload-nginx.sh` deploy hook 自动重载 Nginx，续期演练已通过。

在本机项目目录执行：

```sh
pnpm test
pnpm test:live
pnpm run deploy:check  # 构建并预演同步，列出将更新、删除的文件，不改动线上
pnpm run deploy       # 构建并同步 dist/ 到源站
VANTA_URL=https://vanta.vanillacake.cn node tools/live.mjs  # 公网操作回归
```

构建在本机完成，源站使用 SSH 和 rsync 接收静态文件。同步会移除站点目录中不再属于构建产物的文件，并排除 `.DS_Store`；更新静态文件无需重载 Nginx。

站点首页和模型使用 `Cache-Control: no-cache`，带哈希的 `/assets/` 使用一年不可变缓存。发布后检查首页及其引用的脚本、`/models/Elle_Vanta.glb`、`/models/UAL1_Standard.glb`、`/models/UAL2_Standard.glb`、`/audio/bgm.mp3`、`/audio/sfx/` 下的音效和 `/credits.html` 均返回 200，再验证标题页进入战斗。

## 模型与动画

- `assets-src/models/` 保存原始模型及各自授权说明。Elle 采用 CC BY 4.0，Quaternius 模型和动作库采用 CC0，不能将全部资源标为 CC0。
- `src/art/anims.ts` 将固定逻辑帧映射为动画时间，攻击动作的关键帧对齐命中时刻。
- `pnpm models:pack` 根据动画表裁剪资源，再将动作烘焙到 Elle 的 VRoid 骨骼并写入 `public/models/`。增加动画引用后需要重新打包；缺失动画会令命令失败。
- `tools/pack-elle.mjs` 处理 Elle 的坐标和尺寸、精简骨骼矩阵、压缩贴图，并按 60Hz 烘焙动画，保留原动作时长。无需 Blender 或运行时重定向。
- `tools/hero-motion.mjs` 在烘焙时塑造主角的站姿、拖剑跑姿、收膝跳跃、挥刀时的躯干扭转与抬手引爆动作；敌人继续使用原动作。轻击用分段时间映射表现蓄势、瞬间挥出和收势。
- `src/three/elle.ts` 合并 Elle 的网格并设置银白发、青蓝材质；保留原贴图细节与完整服装。
- 主角脚下有一片随身移动的地面光斑，同一位置的一盏点光源从下方照亮主角，也会照到靠近的敌人，离地越高越弱；腿部周围有一层淡淡的光雾；主角自身也发光，表现为沿轮廓的一圈蓝色亮边。超载时光斑、灯光和亮边转为紫粉色。主角背后不再有橙色飘带。
- `src/three/stage3d.ts` 管理角色、武器、骨骼挂点与残影。角色挂点在逻辑步和渲染时均更新；重开会释放实例资源，保留共享模型。
- `src/three/costume.ts` 在绑定姿势下生成服装和护甲，按材质合并成骨骼网格。每种外观共享几何体，每个角色独立控制闪光、发光与透明度；残影使用相同的服装轮廓。

## 光效参考

`assets-src/vfx/REFERENCES.json` 记录素材来源和使用方式。已收集 Cethiel 的 Weapon Slash - Effect 及 Kenney 的 Particle Pack 原始压缩包、预览与许可信息，供后续美术迭代使用。运行时的高饱和体积刀光和垂直剑气由 `src/art/bladeFx.ts` 生成：刀光不是圆规画出的圆弧：外缘随挥砍向外舒展成螺旋，到刀尖处向内收成钩；刀身从细长的尾部逐渐变厚，约三分之二处最宽，再收成尖端；尾部有三缕长短不一的细丝从刀身分出并向后散开。所有轮廓都是平滑曲线，不做抖动、撕裂或断线处理，高亮刃线保持一条连续的线。刀身与亮刃都比此前更厚更宽。叠加半透明体积、饱和辉光与高亮刃线；普通模式保持单刃，超载模式保留错位的蓝粉双刃。参考包不加入线上下载资源。

## 背景

背景是一座夜里的废弃电厂，用实拍照片合成，不再是手绘的卡通城市。素材全部来自 Poly Haven（CC0，被大量项目采用）：两张全景 Peppermint Powerplant 与 Peppermint Powerplant 2（Andreas Mischok 拍摄），以及地面用的 Metal Plate 贴图（Rob Tuytel）。来源、裁切范围和用途记录在 `assets-src/backdrop/SOURCES.json`。

- 全景只取地平线附近的一条带子，它左右首尾相接，可以作为视差层无限滚动。
- `node tools/pack-backdrop.mjs` 把白天的照片调成夜景（压暗、去色、偏冷蓝），输出到 `public/backdrop/`：远景（涡轮机大厅，带一层尘雾般的模糊，顶部融进黑暗）、中景（厂房内部，顶部用透明度渐隐）、一根铆接钢柱和花纹钢板地面。
- `src/art/stage.ts` 在启动时把钢柱排进近景层，补上垂挂的电缆、一段塌下来的走道，再叠加还通着电的东西：钢柱上断断续续的冷色灯带、状态灯、一块仍在投影的全息警示牌（整体会不规则地明暗起伏，偶尔瞬间掉电），以及透过窗户照在尘埃里的月光光柱。
- 每一层的顶部都融进黑暗，所以主角飞到高处时不会再看到柱子或布景的断口。

## KOOK 小游戏

游戏已按 KOOK 小游戏 SDK（`@kookapp/kook-minigame-sdk@1.3.1`，版本固定）接入，同一份构建既能在 KOOK 里作为小游戏运行，也能在浏览器里直接打开玩，两边玩法完全一样。接入代码都在 `src/core/kook.ts`。

**在 KOOK 平台上的配置**

- 游戏页面地址：`https://vanta.vanillacake.cn/`（HTTPS；站点没有禁止被嵌入的响应头，可以放进 KOOK 的 iframe）。
- 游戏人数：固定为 1。游戏不使用邀请、参与者、频道成员等任何多人接口。
- OAuth scope：不需要，留空即可。游戏从不调用 `session.get()`，不会弹出授权框，也不读取任何用户资料；如果后台要求至少填一项，填最小的 `get_user_info` 也不会被用到。
- 不需要游戏后端，也不需要 `mini_game.context` 权限。
- 只信任 SDK 默认的 `https://www.kookapp.cn`，没有追加测试来源。要在 KOOK 提供的测试环境联调时，在 `createKookClient()` 里加 `allowedHostOrigins`（见 SDK 文档「测试环境配置」）。

**游戏做了什么**

- 页面一启动就创建客户端并 `ready()`，和资源加载同时进行；标题页可以操作时上报 `loaded`，资源加载失败时上报 `failed / game_resource_failed`（宿主在 ready 后只等 60 秒）。
- 宿主把游戏隐藏时：战斗定格（打开作战终端）、音乐暂停；重新显示后音乐恢复，由玩家按 Esc 继续。宿主关闭本局时停止音乐并定格。
- 连接恢复（epoch 变化）后重新 `ready()` 一次；连接断开不影响继续玩，因为游戏里没有任何依赖 KOOK 的交互。
- 页面卸载时 `destroy()`。
- 作战终端里按宿主能力多出两行：「全屏」（`ui.requestFullscreen`，在按键事件里直接调用，符合"必须由用户点击触发"的要求）和「退出游戏」（`lifecycle.leave`；游戏没有存档或房间要清理，直接交给 KOOK 关闭）。宿主不支持的能力对应的行不出现。
- 资源署名页在 KOOK 里通过 `ui.openExternalLink` 打开，保留 KOOK 的跳转提示。

**独立运行**

- 直接在浏览器打开时，页面不在任何框架里，根本不会下载 SDK（它被打成单独的文件，按需加载），`window.__kook.state` 为 `standalone`。此时终端里的「全屏」用的是浏览器自己的全屏，没有「退出游戏」。
- 被 KOOK 以外的页面嵌入时，SDK 会因为找不到宿主而超时（约 10 秒，`BOOTSTRAP_TIMEOUT` 或 `UNSUPPORTED_ENVIRONMENT`），游戏不等它、照常可玩，状态记为 `unavailable`。

**验证情况**：`pnpm test:live` 覆盖了「独立打开不加载 SDK」和「被非 KOOK 页面嵌入时照常可玩」两种情况。与真实 KOOK 客户端的握手、加载上报、隐藏／关闭、全屏和退出，这台机器上没有 KOOK 宿主可测，上线前需要在支持小游戏的 KOOK 客户端里按 SDK 文档的「接入检查」走一遍。

## 声音

目前只有两类声音，其余音效已全部撤下：

- 背景音乐：每关一首，都带明确的鼓点，来自 Kevin MacLeod（incompetech.com，CC BY 4.0，免费配乐里采用最广的曲库之一）。第一关《Cyborg Ninja》，第二关《EDM Detection Mode》。我听不到声音，鼓点是用程序量低频底鼓的规律性来确认的：前者整首每一秒都有底鼓，后者是 128 BPM 的规整四拍。CC BY 要求署名，已写进署名页和终端的资源署名一栏。
- 区域肃清的提示音：Kenney 的 Interface Sounds 里的 `confirmation_002`（CC0）。

先前接入的整套战斗音效（挥砍、命中、闪避、处决等，选自 Kenney 的几个 CC0 包）听感不好，已撤下。代码里那些发声位置都还在：`src/audio/sfx.ts` 的 `CUES` 列出全部时机，只有在 `MIX` 里登记了音量的才会真正发声。以后重新挑选时，除了许可证，还要看口碑和采用率，并且先试听少量样本再铺开；届时把原始文件放进 `assets-src/audio/sfx/`、在 `SOURCES.json` 和 `MIX` 里各加一项即可。

`assets-src/audio/SOURCES.json` 记录来源、许可和用途。`pnpm audio:pack` 裁掉音效开头的静音、裁剪到最长时长、统一峰值电平、加收尾淡出并转成单声道 mp3 写入 `public/audio/sfx/`；音乐转为 112 kbps 立体声 `public/audio/bgm.mp3`。需要 ffmpeg（在 PATH 中，或用 `FFMPEG=/路径/ffmpeg` 指定）。打包结果已随仓库保存。

运行时由 `src/audio/sfx.ts` 负责：

- 浏览器只允许在访客按下按键或点击之后发声，所以第一次按键或点击时才创建音频上下文。只用手柄时浏览器不认为这是一次「按下」，要先碰一下键盘或鼠标才有声音。
- 音乐由 `<audio>` 元素流式播放，不整首解码进内存。暂停时音乐被压低并滤掉高频，像隔了一层；阵亡、超载蓄力的俯视慢放和处决演出期间程度依次减轻；通关时淡出，重新开始后从头播放。切到后台标签页时暂停。
- M 键静音，选择保存在浏览器本地（`vanta.muted`）；暂停页显示当前状态。
- `?test` 脚本运行时完全静音，不创建音频上下文，也不下载音频。

pnpm test:enemy                                  # 濒死动作与身上标识、过量伤害、Boss 终结规则、目标按键提示
pnpm test:overload                               # 超载时长、冷却、伤害、锚点斩击、重击范围及双色光效

自动对战会补充玩家生命值，用于流程与运行时回归，不代表难度和平衡性验收。实时测试等待实际游戏状态变化，软件渲染环境也可运行。

命中停顿（卡肉）只属于重击第二段（普通与超载都是，16 帧）；其余一切攻击——轻击、其他各段重击、下劈、闪避斩击、光墙和光刃——命中时都不定格。命中反馈由配合更亮的高饱和体积刀光和命中火花；普攻与重击中，每道刀光的明暗层使用相同位置、角度和尺寸，普通模式合为单刃、超载模式保留错位双刃，以多层饱和辉光和高亮刃线突出刀光；挥空不触发停顿。除处决外，只有两处会震屏：极限闪避的反击（特效等同处决），以及超载光幕第二刀触地和拖行的时候；其余攻击不触发震屏或镜头缩放冲击。处决首个爆发或斩击就发出单道水波纹，按线性速度在 0.72 秒特效时间内扩散，连锁处决会替换余波。普通兵、枪手与无人机先被快速挑空，主角立即跳起斩击一次，斩击同时穿过目标身体并引爆核心；大型敌人保留斩击，以终结斩引爆。所有处决都以同一个绽放收尾：核心过曝成白色，十余道长短、粗细各不相同的光瓣从核心向外展开并越过画面边缘，外缘带蓝粉色晕，其间夹着细光束和细针碎光，同时全屏泛起一层淡蓝白色的光幕，画面四周的暗角随过曝程度减弱，使光瓣一直亮到边缘；随后光瓣变细、缩短并收拢。大型敌人的绽放按取景放大。处决震屏峰值为 20–26。起跳、斩击和绽放展开以原有速度播放，绽放刚达到最大尺寸和亮度时才进入 0.16 倍速，持续约 0.63 秒；小型目标在这段时间里穿身而过，并对位移和角色动作逐帧插值，随后以正常速度短暂收势并交回控制。处决带两段以目标为中心的全屏动态模糊：画面沿指向目标的方向拉伸，并带少量旋转和均匀柔化，因此顺着方向的光瓣边缘也会变软。第一段较轻，出现在慢放之前，跟随起跳、突进和每一刀；第二段约为三倍半的强度，与慢放同时开始，并在慢放结束前逐渐消退。HUD 不受模糊影响。主角处于超载时发动的处决使用蓝粉版本：光瓣外缘换成更宽、更饱和的蓝粉交替色晕，核心两侧分别泛蓝和粉，每道斩痕和刀光都成对出现蓝粉双线，光幕偏淡紫。处决与完美闪避反击共用特效峰值触发规则，后续演出也以视觉峰值作为慢放起点；小型目标处决后角色留在目标另一侧半空，可立即接空中攻击，大型敌人在爆发后 16 个演出帧恢复控制。碎光和目标消散在恢复操作后继续，丢弃演出期间缓存的攻击输入并清除余震。

水波纹：处决开场时发出一圈清弹波纹（会带走敌方子弹），斩击绽放的一刻再从命中点荡开一圈只供观看的水波纹，随绽放散去而扩散到全屏；开启超载、极限闪避反击和超载光幕第二刀触地时也各有一圈。

小体型敌人（普通兵、枪手、无人机）的处决：穿身斩的 0.16 倍速慢放结束后，演出不恢复原速，而是以 0.5 倍速再播约 0.43 秒，让绽放的光花慢慢散去、主角继续向前滑出，然后才交还控制。大体型敌人和 Boss 的处决不变。

跳跃高度按固定 60 Hz 的实际顶点调整为原来的 1.5 倍：普通跳 468、二段跳约 368；最短的轻点跳约 300 个世界单位。平台已整体抬高（下层离地 360、上层离地 600），重击连段打到一半不会再被带上平台；上平台需要按住跳跃键跳满，或用二段跳。

## 结构

- `src/audio/` 音效与音乐的播放、混音表和静音设置
- `src/art/` 程序化贴图、动画时间映射，以及把实拍背景层组装成场景的代码
- `src/three/` Three.js 模型、武器、骨骼挂点、残影与无人机精灵适配
- `src/game/` 角色、敌人与 Boss、特效（含水波纹）、处决演出、动态模糊滤镜、开场走廊的说明牌与小怪
- `src/scenes/` 启动、标题、战斗主场景、HUD
- `src/core/` 键盘/手柄输入、输入缓冲与确定性随机数
- `tools/` 自动对战、运行时回归、截图、模型、音频与背景处理
- `.claude/skills/` Phaser 官方 Agent Skills（随 phaser 包分发）
